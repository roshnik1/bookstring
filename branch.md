# Planning and Organization
With version control!

The core concept here is to integrate architecture planning, detailed documentation, and ideation naturally around and alongside code. This may happen in two ways:

## Markdown Files
Standalone [[markdown]] files (like this one!) given `{ALLCAPS}.md` or `{dash-case}.md` names. These may include [[yaml]] [frontmatter](#markdown.frontmatter) and/or [data blocks](#markdown.data).

## Code Documentation
In [[python]], use [docstrings](#python.conventions.doctrings) and in [[typescript]] use [jsdocs](#typescript.jsdoc).
